## Integration branding

Use **Drex for PostgreSQL** as the display name. PostgreSQL is the official project name;
Postgres is an [accepted alias](https://www.postgresql.org/about/policies/project-name/).
Package names, imports and existing repository paths remain unchanged.

The [PostgreSQL trademark policy](https://www.postgresql.org/about/policies/trademarks/)
allows truthful compatibility references without implying affiliation or endorsement. It also
restricts presenting its marks with other trademarks or logos. The README therefore uses Nace
artwork only, with a plain-text reference to the database. Downloadable artwork is not permission
for a combined logo header.
